`find_leads` returns a `taskId`. `create_campaign` can return a `searchTaskId` for its first search. Call `get_task` with either ID to follow that search.

```json
{
  "taskId": "TASK_ID"
}
```

## Status and result

| Field | Meaning |
| --- | --- |
| `status` | `running`, `done`, or `failed` |
| `total` | Number of pages requested |
| `result` | Search counts when available: found, checked, added, duplicates, and rejected |
| `error` | Failure reason, if one was recorded |

Wait a few seconds between checks. A search can add fewer pages than requested. If `find_leads` returns `alreadyRunning: true`, follow that task rather than starting another one.

Tasks can only be read from the workspace of the current connection. The dashboard's AI progress window also shows search progress.

## Email drafting

`write_emails` returns its drafting summary directly. Read saved drafts through `list_emails` and review them in the dashboard. This API has no asset generation, export, or download tools.
