Reachloom exposes a remote [MCP](/ai/mcp) server at `https://my.reachloom.app/mcp`. It uses Streamable HTTP and supports OAuth access tokens or workspace API keys as bearer tokens.

- [Authentication](/api/authentication): endpoints, credentials, workspace selection, and limits.
- [Tools](/api/tools): every registered tool and its inputs.
- [Background tasks](/api/jobs): follow lead searches with `get_task`.

Every connection acts for one person in one workspace. Membership is checked when credentials are used. An agent can read and prepare outreach; approval, sending, starting campaigns, and destructive actions stay in the dashboard.

Tool responses contain JSON as text. Expected errors return `isError: true` with a readable message. Unexpected errors return a generic message.
