Start with the server address shown in the workspace's **Settings → MCP**. The hosted address is `https://app.reachloom.app/mcp`.

## Authentication fails

A `401` means the key or access token is missing, expired, revoked, or no longer has access to the workspace.

For an API key, check the `Authorization: Bearer` header and use a key starting with `rl_live_`. Keys are shown only once; revoke a lost key and create another in **Settings → Developer API**.

For OAuth, reconnect from the client. Choose a workspace you can still open. Removing a member also revokes that person's keys and agent connections for the workspace.

## The wrong workspace appears

A connection is limited to one workspace. Reconnect and choose the right one, or create a key from that workspace's settings. There is no tool to switch an existing connection to another workspace.

## A campaign cannot be changed

Pause the campaign or turn on **Review before sending** in the dashboard. MCP blocks changes that could feed an active campaign sending without review.

## A task failed or added fewer pages

Use `get_task` with the returned task ID. Read `error` for a failed task. A successful search can add fewer pages because candidates were duplicates, excluded, unavailable, or unsuitable.

There is no export job or file download flow in this MCP server.

## A tool is missing

Check the [tool reference](/api/tools). MCP prepares outreach; it does not send, approve, delete, or manage settings. Use the dashboard for those actions.

## Too many requests

A `429` response includes `retry-after`. Wait before trying again. Searches, drafting, and inbox sync also have hourly limits. A billing or usage error needs to be resolved in **Settings → Billing**.
