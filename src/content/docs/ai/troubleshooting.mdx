Start with the server address shown in the workspace's **Settings → MCP**. The hosted address is `https://my.reachloom.app/mcp`.

## Authentication fails

A `401` means the key or access token is missing, expired, revoked, or no longer has access to the workspace.

For an API key, check the `Authorization: Bearer` header and use a key starting with `rl_live_`. Keys are shown only once; revoke a lost key and create another in **Settings → Developer API**.

For OAuth, reconnect from the client. Choose a workspace you can still open. Removing a member also revokes that person's keys and agent connections for the workspace.

## The wrong workspace appears

A connection is limited to one workspace. Reconnect and choose the right one, or create a key from that workspace's settings. There is no tool to switch an existing connection to another workspace.

## A campaign cannot be changed

Pause the campaign or turn on **Review before sending** in the dashboard. MCP blocks changes that could feed an active campaign sending without review.

## A task failed or added fewer pages

Use `get_task` with the returned task ID. Read `error` for a failed task. A successful search can add fewer pages because candidates were duplicates, excluded, unavailable, or unsuitable.

There is no export job or file download flow in this MCP server.

## A tool is missing

Check the [tool reference](/api/tools). MCP prepares outreach; it does not send, approve, delete, or manage settings. Use the dashboard for those actions.

## Too many requests

Only the limit of 120 requests per minute returns an HTTP `429`. It includes `retry-after: 60`, so wait a minute and try again.

Creating campaigns, adding pages, searching, drafting, and inbox sync also have hourly limits. These do not return `429`. The tool answers with an error (`isError`) that says `Too many requests of this kind this hour. Wait and try again.` The hour is a fixed clock hour, so the count starts again at the top of the next hour.

A billing or usage error needs to be resolved in **Settings → Billing**.

## A draft was refused

`draft_reply` and `edit_draft` run the draft check. A reply can be up to 4,000 characters even though the input accepts more. The check also refuses unfilled placeholders, text that says AI wrote it, and links to sites other than yours, your booking link, or the page's own site. A first email needs a one-line subject of at most 150 characters and a body of 40 to 4,000 characters. `draft_reply` also refuses when an answer is queued or one you wrote is waiting.

## A request returns 503

`The MCP server needs the signed-in PostgreSQL runtime.` means the server is not running in the mode that MCP needs. Contact [hello@reachloom.app](mailto:hello@reachloom.app).

## The page id is not found

`create_campaign` with `contentAssetId` answers `No such page. Use list_content.` when the id is unknown or belongs to another workspace. Read the id from `list_content` in the same connection.
