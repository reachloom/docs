Reachloom's remote MCP server lets an AI tool read your workspace and prepare outreach. It uses **Streamable HTTP** at:

```txt
https://my.reachloom.app/mcp
```

## Choose how to connect

Open the workspace's **Settings → MCP** for the server address and setup examples.

- [OAuth](/ai/mcp-oauth): sign in, choose a workspace, and allow the connection.
- [API key](/ai/mcp-api-key): create a key in that workspace's **Settings → Developer API** and send it as a bearer token.

Both methods act for one person in one workspace. To work in another workspace, make a separate connection or key.

## Check the connection

Ask your agent:

> Show my Reachloom workspace status and list its campaigns.

It should call `get_status` and `list_campaigns`. Then try an [example workflow](/ai/workflows).

## What stays in the dashboard

MCP can read campaigns, search for pages, and write drafts. It cannot approve or send email, turn campaigns on, mark wins, archive conversations, delete records, or change members, billing, keys, or exclusions.

It also cannot add work to a campaign that is on and sends without review. Pause the campaign or enable **Review before sending** in the dashboard first. See the [full capabilities](/ai/mcp-capabilities) and [tool reference](/api/tools).
