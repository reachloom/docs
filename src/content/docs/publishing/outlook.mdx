Open **Settings → Mailbox**, choose **Connect mailbox**, and pick **Outlook / Microsoft 365**.

## Connect and test

1. Sign in to the Microsoft account you want to send from.
2. Allow Reachloom to send mail and to read mail. Microsoft calls these permissions Mail.Send and Mail.ReadWrite. Reachloom also asks to sign you in and to stay connected (User.Read and offline_access).
3. Return to Reachloom and check the connection status.
4. Send yourself a test email.

Reachloom signs campaign emails with the name of the person who connected the mailbox.

If sending permission is missing, the connection is not saved. If reading permission is missing, emails can be sent but replies cannot appear in the Inbox. Connect again and allow both.

## Work and school accounts

Some Microsoft 365 organizations ask an administrator to approve apps before people can use them. If you see a message asking for approval, send the request to your administrator, then connect again.

## What Reachloom reads

Reachloom reads conversations started by its own sent emails. It does not import your whole mailbox. See [choose a mailbox](/publishing/mailbox).

## Reconnect or disconnect

If the status says **Needs reconnecting**, connect again. Disconnecting removes the workspace's connection and the stored access. You can also remove Reachloom in your Microsoft account's app permissions.
