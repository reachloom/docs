Use the account menu to review your profile, sessions, and sign-in connections. Workspace agent credentials are under **Settings → Developer API**.

## API keys

Create a named key in the workspace that the agent should use. The full key appears only once. Give each client its own key and store it in the client's private configuration.

Keys belong to one workspace and the person who created them. Any member can review the workspace's keys and revoke one. A key stops working when revoked or when its creator loses workspace access.

## Connected agents

OAuth asks you to choose one workspace. Review **Connected agents** in that workspace's **Developer API** settings and disconnect tools you no longer use.

An agent can read workspace data and prepare campaigns and drafts. It cannot send email or manage access. See [MCP capabilities](/ai/mcp-capabilities).

## Sessions and deletion

Use the account's session controls to end sessions you no longer need. Workspace deletion is a separate action under **Settings → Delete workspace** and removes that workspace's data. Account deletion removes your account and its related access; check shared workspaces before deleting it.

For connection errors, see [MCP troubleshooting](/ai/troubleshooting).
