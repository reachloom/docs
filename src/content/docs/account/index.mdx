Use the account menu for your profile, sessions, and sign-in connections. Use **Settings** inside a workspace for that product's members, billing, mailbox, notifications, and outreach controls.

- [Billing and usage](/account/plans) explains the preview and subscription limits.
- [Account access](/account/access) covers sessions, keys, and connected agents.
- [Members](/account/members) explains invites and shared access.
- [Notifications](/account/notifications) covers Slack, Discord, webhooks, email, and the weekly report. See [Webhooks](/api/webhooks) for the message format.
- [Search Console](/account/search-console) connects Google Search Console for read-only search numbers.
- [Integrations and feature requests](/account/feature-requests) explains the Request buttons for what is missing.
- [Exclusions](/account/exclusions) manages blocked contacts and domains.

For help, use the feedback option in the dashboard or email [hello@reachloom.app](mailto:hello@reachloom.app). Include the page you used and the error message, without keys or passwords.
