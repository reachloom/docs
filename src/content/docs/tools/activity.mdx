Open a campaign's **Activity** screen to check searches, drafts, queued emails, sends, and problems. Use it when the campaign seems quiet or a message did not leave.

## Check waiting work

Start with the message shown on the draft or queued email. Common reasons include a paused campaign, a disconnected mailbox, sending hours, a daily limit, a blocked contact, or a draft that needs changes.

A queued email can wait after its cancel delay ends. The worker checks the current rules again before sending; the delay is not a guaranteed send time.

The [Inbox](/publishing/conversations) shows the messages themselves. [Results](/publishing/results) shows sends, replies, and wins over time.

## AI work

Lead searches and email drafting have their own progress window. Reopen it from the sidebar to see the result or error. If work failed, read the reason before starting it again.
